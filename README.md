# 💰 Salary Predictor

A beginner-friendly Machine Learning regression project that predicts employee salaries based on input features. The model was built using Linear Regression and deployed with Streamlit for real-time salary predictions.

## 🚀 Live Demo

https://salary-predictor-regression.streamlit.app/

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Scikit-Learn
* Streamlit
* Joblib

## 🤖 Model Used

* Linear Regression

## 📊 Model Performance

| Metric     | Score     |
| ---------- | --------- |
| Train R²   | 0.9455    |
| Test R²    | 0.9372    |
| Train MSE  | 1,208,180 |
| Test MSE   | 1,373,518 |
| CV R² Mean | 0.9402    |

The small difference between Train and Test R² (0.0083) indicates that the model generalizes well and shows minimal overfitting.

## ⚙️ Features

* Salary Prediction using Regression
* Real-Time Predictions
* Simple and Interactive Streamlit Interface
* Data Preprocessing and Feature Handling

> **Note:** This was one of my first Machine Learning projects and was built mainly for learning regression concepts and the complete ML workflow. The project uses a simple Linear Regression model with basic preprocessing techniques and focuses on understanding the fundamentals before moving to more advanced algorithms and optimization methods.
